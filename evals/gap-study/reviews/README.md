# The pre-freeze reviews, as they were written

Each file is one fresh-context reviewer's report, verbatim, at the point it was written. Nothing has
been edited into agreement with what happened next, including the reports that were wrong.

The reviews ran headless with a working directory outside this repository and outside the operator's
assistant tree, so no instruction file, memory or profile reached them; each was given only the files
named in its brief. A report that names no person and no absolute path is evidence the blindness
held, and each was swept for both before being committed here.

Reviews 2 through 11 are here. Review 1's report was not kept, and saying so is more useful than a
gap a reader has to explain to themselves.

They are numbered in the order they ran. Read them together and the shape is the point: the early
passes found defects that would have voided whole task rows, the middle ones found prose that
claimed more than the record supported, and review 10 ruled freeze. What stopped the freeze was not
a review at all — it was reading the folder being prepared for review 11.
