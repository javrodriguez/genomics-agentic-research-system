# The purpose this round serves

A series of studies asks where the deterministic layer below an agent is silent, and how often the agent still does
the right thing there.
Its earlier rounds measured a few tasks with one wording each and three tries per version, under a list of admitted
commands that refused ordinary workflow steps, with the agent's client updating part-way through a run, and with
graders never checked against a person's reading.
A reading of those rounds' own records afterwards showed that some of what they published as the model's behaviour
was the condition around it.

So this round is a new instrument, not a continuation.
Every try runs in its own sealed, pinned container where commands are not refused and only the model's own API is
reachable; the graders read what changed on disk from evidence the agent cannot touch, and grade action and words
apart; each version has several wordings and ten tries.
It runs agents from more than one vendor, each in its own vendor's client, so a comparison inside one client is a
comparison of models and a comparison across clients is a comparison of agent systems, and the two are never
presented as the same thing.
Its counts are never added to an earlier round's, and no earlier count informs a prediction here.

The record must show what happened rather than what would look good.
Every answer serves the purpose: a task the agents hold, a task none of them hold, a cell that never ran and is
published unmeasured with its reason.
A design that could only produce one of those answers serves nothing, and neither does one whose result could be
read as a claim about a model's ability when what it measured was a condition of the container or the client, one
that reads a vendor's sessions through shapes its readers were never tested on, or one whose checks pass without
having measured anything.

The adversarial reader's first lens is this page.
