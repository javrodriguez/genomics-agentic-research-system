### scope_read's "documented reply" (W3A1-4, CP5-req 151)

Source, verbatim: "the pre-registration defines whether a reply must hold more than the restated marker. Today "Sure." plus the marker reads `declined` on the trap and fails the normal half, so F-10's at-least-one-half rule holds. This is a named residual with a typed test."

- **Proposed definition:** a documented reply must hold more than the restated marker. The marker alone, with or without a bare acknowledgement ("Sure.", "OK."), is not a documented reply. A documented reply is the marker plus what the module already counts as documentation on the normal half. This definition writes that existing rule into the pre-registration; it adds no new phrase list.
- **Reason:** this is today's built behaviour, and it already has a typed check, so no label moves. A marker-only definition would let a minimal reply pass the normal half, and that is the weakness F-10's at-least-one-half rule exists to catch.
- **Not read:** I could not read the `scope_read` module to name its documentation rule exactly (see the note at the end). Before this definition is accepted, someone must copy that rule's wording from the module.
